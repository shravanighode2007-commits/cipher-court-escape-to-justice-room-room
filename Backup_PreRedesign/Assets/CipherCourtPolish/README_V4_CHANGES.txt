CIPHER COURT – CONTROLLED VISUAL REBUILD V4

This pass addresses the specific visual issues reported after V3:
- Brighter, warmer investigation-room lighting with fog disabled.
- Real office-set mesh props added to make Levels 1–5 feel occupied and believable.
- Level 5 rebuilt as a complete case-analysis/conference room with rear wall treatment, shelving, cabinets, art, chairs and practical lighting.
- Exit doors receive snug frames to hide the visible gap around the old door geometry.
- A finished, lit corridor appears behind exit doors after they open.
- Clues use a cleaner evidence-tray/file presentation with warm focused lighting.
- Courtroom rebuilt with timber wall panelling, raised judge dais, bench, witness stand, clerk desk, counsel tables, audience benches and formal warm lighting.
- UI palette moved toward the reference: dark panels, white text, red primary menu action, restrained gold accents.

The existing gameplay scenes/scripts remain in the project. Visual decorative prefabs have colliders removed so they do not intentionally block puzzle routes.
Database backend from V3 is retained under /Backend.
