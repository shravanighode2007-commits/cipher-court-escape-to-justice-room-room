1. Front End
The front end is the visual and interactive part of the game through which the player 
experiences the 3D environment and communicates with the system.
Unity 3D game scenes for the courtroom/escape-room environment.
3D character/player controller.
Interactive doors, locks, ﬁles, computers, documents and other objects.
Main Menu, Gameplay UI, Pause Menu and Completion/Game Over UI.
Code-entry and puzzle interfaces.
Clue and hint display.
Timer and objective indicators.
Lighting, textures, animations and audio presentation.
2. Backend
The backend/game logic manages player actions, puzzle validation, game state and 
progression. For the Unity implementation, this logic is primarily handled by C# scripts inside 
the Unity project.
Player movement and interaction management.
Puzzle and cipher validation.
Code and password checking.
Door/area unlocking logic.
Clue and hint management.
Timer and objective management.
Game-state and progression management.
Scene loading and transition control.
Audio and event-trigger management.
